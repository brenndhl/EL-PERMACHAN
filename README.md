# EL PERMACHAN

Apps instalables (PWA) del sistema de facturas del Restaurante El Permachan.

- `index.html` — app para clientes: pedir factura.
- `admin.html` — panel de administración. La clave **no** está en este repositorio: la app la pide una vez y la guarda solo en el móvil.

Publicado con GitHub Pages (rama `main`, carpeta raíz).
